# Backend

Server-side runtime specifications, configuration rules, session and host execution, task
observation, Agent Board relay, and coding-agent registration.

## Domains and shared foundation

* [Agent Registry](agent-registry.md) - Registered coding agents, identities, session keys, capabilities, adapters, and agent integration steps.
* [workspace/](workspace/) - Startup, YAML configuration, PTY/SSH/tmux sessions, pane metadata, split preview serving, and pane URL opening.
* [tasks/](tasks/) - Task collection, state derivation, Codex permission hooks, live event observation, launch/resume, records, summaries, and temporary attaches.
* [agent-board/](agent-board/) - Agent Board architecture, relay, agmsg integration and host tools, and Command Center subprocess execution.

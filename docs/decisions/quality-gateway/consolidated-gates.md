# D3 — Consolidate gates rather than adding them

Recorded 2026-08-28 in the original quality-gateway milestone log.

Independent route-test inventories let new routes be forgotten in several places. One route
authority plus an exhaustive check forces updates, removing the forgetting path instead of adding
another gate. See [quality gateway](../../quality-gateway.md).

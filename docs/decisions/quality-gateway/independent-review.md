# D5 — The author does not grade its own work

Authors retain discarded approaches in context; fresh reviewers see the diff without that bias.
Review remains non-blocking because adversarial reviewers can invent gaps and encourage unnecessary
abstraction or impossible-case tests. See [quality gateway](../../quality-gateway.md).

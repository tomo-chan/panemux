# D1 — Do not raise the coverage threshold above 80%

Recorded 2026-08-28 in the original quality-gateway milestone log.

Raising coverage invites tautological tests that meet a number while reducing regression
protection and refactoring resistance. Keep 80% as a lower bound and strengthen measured scope.
See [coverage](../../development/coverage.md) for the current rule.
